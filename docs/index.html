      How it works

      Each review is split into clauses on sentence punctuation and contrast words (but / however / although…). Aspect keywords (7-aspect lexicon, word-boundary matched) pair each aspect with its local clause, and a compact VADER-style lexical scorer (negation-aware, ±0.05 thresholds) labels the clause. Reviews matching no aspect count as unassigned in the coverage metric. This is a simplified in-browser port for demonstration — the reference implementation (Python VADER + LLM comparison, evaluation tables and insights report) lives in the repository.
